### **Описание системы "AI Code Assistant"**

#### 1. Обзор системы: Что это и для кого?

**AI Code Assistant** — это мощный помощник для разработчиков, встроенный прямо в редактор кода VS Code. Он предназначен для анализа, рефакторинга, документирования и улучшения вашего кода с помощью искусственного интеллекта. Представьте, что у вас есть опытный напарник-программист, который всегда готов провести code review, предложить оптимизацию или написать тесты для вашего кода.

#### 2. Структура и навигация

Приложение представляет собой отдельную панель внутри VS Code, которая разделена на две основные части:

*   **Левая колонка (Сайдбар):** Здесь отображается структура вашего проекта в виде дерева файлов и папок. Это ваш "пульт управления" для выбора кода, который вы хотите проанализировать.
*   **Правая колонка (Основная рабочая область):** Это главный центр взаимодействия с AI. Здесь вы настраиваете подключение, выбираете задачи, пишете запросы и получаете ответы.

Пользователь перемещается по приложению, последовательно работая с блоками в правой колонке сверху вниз: настраивает API, выбирает шаблон, пишет запрос и получает результат.

#### 3. Основная функциональность

##### Что может делать пользователь?

*   **Анализировать код:** Выбирать любые файлы из своего проекта и отправлять их на анализ искусственному интеллекту.
*   **Использовать готовые сценарии:** Применять специализированные шаблоны для конкретных задач, таких как "Поиск багов", "Создание документации" или "Аудит безопасности".
*   **Создавать свои сценарии:** Конструировать и сохранять собственные шаблоны запросов для повторяющихся задач.
*   **Подключать разные AI-модели:** Гибко переключаться между различными провайдерами AI (Google Gemini, OpenAI, OpenRouter) или даже подключать свой собственный сервер.
*   **Сохранять результаты:** Сохранять ответы от AI в виде файлов прямо в проекте для дальнейшего использования.
*   **Предварительно просматривать запрос:** Увидеть, какой именно текст будет отправлен AI, чтобы убедиться в корректности запроса.
*   **Безопасно хранить ключи:** API-ключи хранятся в защищенном хранилище VS Code, а не в открытом виде.

##### Формы и поля ввода

1.  **Дерево файлов (слева):**
    *   **Назначение:** Позволяет пользователю выбрать один или несколько файлов (или целые папки) из проекта для анализа.
    *   **Взаимодействие:** Пользователь ставит галочки напротив нужных файлов/папок.

2.  **Настройки API:**
    *   **Назначение:** Здесь пользователь настраивает подключение к AI-сервисам.
    *   **Поля:**
        *   **Выбор провайдера:** Карточки для выбора между `Google Gemini`, `OpenAI`, `OpenRouter` и `Custom API`.
        *   **API Ключ:** Поле для ввода секретного ключа доступа. Оно скрыто (как пароль) и его можно показать/скрыть.
        *   **URL API-сервера:** Появляется только при выборе `Custom API` для указания адреса своего сервера.
        *   **Модель:** Поле для указания конкретной AI-модели (например, `gpt-4` или `gemini-1.5-pro`).

3.  **Шаблоны промптов:**
    *   **Назначение:** Секция для выбора, создания и управления шаблонами.
    *   **Взаимодействие:** Пользователь может выбрать готовый шаблон (например, "План рефакторинга"), отредактировать свой или создать новый с нуля через специальное модальное окно. В редакторе шаблонов есть поля для названия, описания и двух ключевых частей запроса: "системного промпта" (роль AI) и "пользовательского промпта" (шаблон задачи).

4.  **Ваш запрос:**
    *   **Назначение:** Главное текстовое поле для формулировки задачи для AI.
    *   **Взаимодействие:** Пользователь пишет сюда, что именно он хочет сделать. Например: "Найди возможные утечки памяти в этом коде" или "Объясни, как работает этот алгоритм".

##### Кнопки и элементы управления

*   **"Отправить"**: Главная кнопка, которая запускает весь процесс. Она становится активной, только когда введен запрос, выбраны файлы и настроен API.
*   **"Предпросмотр"**: Открывает окно, где можно детально увидеть, что именно будет отправлено AI: роль, итоговый текст запроса с подставленным кодом из файлов и технические параметры.
*   **"Очистить"**: Сбрасывает текст запроса и снимает выделение со всех файлов.
*   **"Копировать" / "Сохранить" (в секции ответа):** Позволяют скопировать ответ AI в буфер обмена или сохранить его в файл `*.md` в папке `plans` вашего проекта.
*   **Иконки в списке шаблонов (`👁`, `✏️`, `🗑️`):** Позволяют просмотреть, отредактировать или удалить пользовательский шаблон.

#### 4. Пользовательские сценарии (User Journeys)

##### Типичный рабочий процесс: "Получить план рефакторинга"

1.  **Шаг 1: Открытие панели.** Пользователь запускает команду `AI Code Assistant: Open Panel` и видит интерфейс расширения.
2.  **Шаг 2: Настройка API.** Пользователь разворачивает секцию "Настройки API", выбирает, например, `OpenAI`, и вставляет свой API-ключ. Ключ автоматически сохраняется в безопасное хранилище.
3.  **Шаг 3: Выбор файлов.** В левой колонке пользователь находит папку `src/legacy-module` и ставит напротив нее галочку. Все файлы внутри этой папки автоматически выбираются для анализа.
4.  **Шаг 4: Выбор шаблона.** В секции "Шаблоны промптов" пользователь находит и выбирает шаблон **"План рефакторинга"**.
5.  **Шаг 5: Формулировка задачи.** В поле "Ваш запрос" пользователь пишет конкретную цель: *"Этот модуль работает медленно и его сложно поддерживать. Нужно подготовить его к добавлению новой системы скидок."*
6.  **Шаг 6 (Опционально): Предпросмотр.** Пользователь нажимает "Предпросмотр", чтобы убедиться, что его задача и код из выбранных файлов правильно подставились в шаблон.
7.  **Шаг 7: Отправка запроса.** Пользователь нажимает кнопку **"Отправить"**. Появляется индикатор загрузки.
8.  **Шаг 8: Получение результата.** Через некоторое время в секции "Ответ AI" появляется детальный, пошаговый план рефакторинга, сгенерированный AI.
9.  **Шаг 9: Сохранение.** Пользователь доволен результатом и нажимает кнопку **"Сохранить"**. В его проекте, в папке `plans`, создается файл `План рефакторинга_2024-05-20_14-30-00.md` с полным ответом.

##### Дополнительные сценарии

*   **Создание своего шаблона:** Пользователь часто пишет однотипные запросы для генерации тестов. Он нажимает "Новый шаблон", задает ему имя "Написать Jest-тесты", определяет роль AI ("Ты — QA-инженер...") и сохраняет. Теперь этот шаблон доступен для быстрого выбора.
*   **Быстрый вопрос по коду:** Пользователь выбирает один файл, не использует шаблон, а просто пишет в поле запроса: "Объясни мне 56-ю строку в этом файле".

#### 5. Особенности интерфейса

*   **Интерактивность и обратная связь:** Система постоянно дает подсказки. Кнопка "Отправить" неактивна, пока не выполнены все условия, что предотвращает ошибки. Индикаторы показывают, сохранены ли ключи. Всплывающие уведомления сообщают об ошибках.
*   **Сохранение контекста:** Приложение запоминает введенный запрос, выбранные файлы и настройки API между сеансами работы для конкретного проекта. Это позволяет продолжить работу с того же места, где пользователь остановился.
*   **Прозрачность:** Функция "Предпросмотр" дает пользователю полный контроль над тем, какая информация уходит на сторонний сервер, что повышает доверие к инструменту.
*   **Гибкость:** Возможность подключения разных AI-провайдеров и создания собственных шаблонов делает инструмент универсальным и адаптируемым под любые задачи и бюджет.
